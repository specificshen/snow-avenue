# Snow Avenue · 雪中秋林路

把一张照片（初雪后的秋日公园林荫路：左侧红枫、绿树、金黄树冠，右侧挂雪的赭色树，湿沥青路、浓雾、两盏路灯和一段栏杆）用 Three.js 做成的实时 3D 场景。完全程序化生成，没有贴图文件，也没有模型文件。

## 运行

```bash
bun install && bun run dev
```

用 Chrome 或 Edge 打开终端里打印的地址（默认 http://localhost:5173）。`bun run build` 会把产物打到 `dist/`。

## 操作

- 按住鼠标左右拖：镜头左右转一点（±0.3 弧度）。镜头机位按照片固定，所以不提供自由漫游。
- 默认有缓慢飘落的雪。

## URL 参数

| 参数 | 说明 |
|---|---|
| `quality=low\|medium\|high` | 叶片数量和像素比，默认 `medium` |
| `dpr=2` | 覆盖像素比 |
| `snow=0` | 关闭飘雪 |
| `fixed` | 定格：不飘雪，镜头不动（截图用） |
| `size=535x1024` | 固定画布尺寸 |
| `mask=road` | 只画路面掩码（对比工具用） |
| `seed=7` | 随机种子 |

## 结构

- `src/camera.ts`：和照片对齐的相机。眼高 1.6 m，垂直 FOV 78°，用镜头平移把消失点放到照片里的位置；`ground(u,v)` / `atDepth(u,v,d)` 把照片像素坐标换算成世界坐标。
- `src/layout.ts`：整个场景按照片坐标写成数据表，包括每棵树的位置、树冠团块、色板、积雪量，以及路灯、栏杆、雾和天空。调构图只改这里。
- `src/tree.ts`：树干、枝条（枝条朝上的面带积雪顶点色）、实例化叶片卡片。
- `src/world.ts`：湿路面（粗糙度贴图加清漆和环境反射）、雪地路肩、落叶、路灯、栏杆、远处的树、飘雪、雾。
- `src/textures.ts`：程序化的叶簇、雪地、沥青贴图。
- `scripts/capture.mjs`：Xvfb 加有头 Chrome（SwiftShader）截图。
- `tools/iter.sh`、`tools/compare.py`、`tools/regions.py`：截图，然后和照片做并排图、50% 叠加图、8×16 网格色差、路面 IoU 和分区取色对比。

## 和照片的差距

- 照片是真实摄影，这里是实时程序化渲染，做不到像素级一样。最终网格平均色差约 23/255，路面轮廓 IoU 0.95。
- 树冠是一张张叶片卡片拼出来的，近看能看出卡片边缘，层次没有照片里那么细；照片右侧那种细密、挂雪的枝杈网也只是近似。
- 路面能反射天空和雾，但不反射树。照片里路面上那种细碎的高光和水痕更丰富。
- 雾是指数雾。照片中景那团灰色、半透明的枯枝层，这里比照片更空、更亮。
- 为了在相机里和照片的像素位置对上，路灯和栏杆的高度是倒推出来的，换个机位看比例会偏大。
